# 대전시 투표사무원 자동배정 시스템

> 신청자의 주소를 좌표로 변환하고, 투표소와의 거리를 계산해 가까운 신청자를 우선 배정하는 웹 기반 프로토타입입니다.

[배포 페이지 바로가기](https://qo3op.github.io/2026-daejeon/)  
[GitHub 저장소](https://github.com/qo3op/2026-daejeon)

---

## 프로젝트 개요

대전시 투표사무원 신청자와 투표소 정보를 바탕으로, 신청자 주소와 투표소 위치 사이의 직선거리를 계산해 자동 배정 결과를 만드는 프론트엔드 프로토타입입니다.

백엔드 서버 없이 GitHub Pages에서 실행되며, CSV 업로드와 카카오 주소 변환 API를 활용해 기본적인 자동 배정 흐름을 확인할 수 있습니다.

---

## 핵심 기능

| 구분 | 기능 |
|---|---|
| 신청자 관리 | 신청명단 CSV 업로드, 주소 좌표 변환, 좌표 포함 명단 다운로드 |
| 투표소 관리 | 투표소 CSV 업로드, 샘플 투표소 불러오기, 투표소 좌표 관리 |
| 자동 배정 | 위도/경도 기준 거리 계산, 가장 가까운 신청자 우선 배정 |
| 결과 확인 | 배정 결과 테이블 확인, 엑셀에서 열 수 있는 CSV 다운로드 |
| 보안 | 카카오 JavaScript 키를 코드에 저장하지 않고 브라우저 localStorage에 저장 |

## 자동 배정 기준

1. 투표소별 필요인원만큼 배정합니다.
2. 이미 배정된 신청자는 중복 배정하지 않습니다.
3. 신청자와 투표소 모두 위도/경도가 있어야 거리 계산 대상이 됩니다.
4. Haversine 공식을 사용해 직선거리 km를 계산합니다.
5. 거리가 가까운 신청자를 우선 배정합니다.
6. 선호구, 선호동 정보가 있으면 배정 사유에 반영할 수 있도록 구조화했습니다.

## CSV 입력 형식

### 신청명단 CSV 권장 컬럼

```csv
부서명,성명,직급,생년월일,연락처,주소,가능투표유형
총무과,홍길동,주무관,1990-01-01,01000000000,대전광역시 서구 둔산동,both
```

신청명단은 위도, 경도 컬럼이 없어도 업로드할 수 있습니다.  
주소 좌표 변환이 성공하면 내부적으로 위도, 경도 값이 추가됩니다.

### 투표소 CSV 권장 컬럼

```csv
구분,자치구,행정동,투표소명,주소,필요인원,위도,경도
사전투표소,서구,둔산동,둔산1동 사전투표소,대전광역시 서구 둔산동,2,36.3504,127.3845
```

## 카카오 주소 변환 설정

카카오 JavaScript 키는 GitHub에 올리지 않습니다.

사용자는 화면 상단의 `카카오 JavaScript 키` 입력칸에 키를 입력하고 `키 저장`을 누르면 됩니다. 저장된 키는 현재 브라우저의 localStorage에만 보관됩니다.

카카오 개발자 콘솔의 Web 플랫폼 도메인에는 아래 주소를 등록합니다.

```text
https://qo3op.github.io
```

## 실행 방법

GitHub Pages 배포 주소:

```text
https://qo3op.github.io/2026-daejeon/
```

로컬에서 확인하려면 `index.html` 파일을 브라우저로 열면 됩니다.  
단, 카카오 주소 변환은 GitHub Pages처럼 등록된 웹 도메인에서 사용하는 것을 권장합니다.

---

## 결과 다운로드

자동 배정 후 `결과 확인` 탭에서 `결과 엑셀 다운로드` 버튼을 누르면 CSV 파일이 내려받아집니다.

CSV 파일은 엑셀에서 바로 열 수 있도록 UTF-8 BOM을 포함합니다.

---

## 보안 처리

- 카카오 JavaScript 키는 코드에 포함하지 않습니다.
- `.env`, CSV, 엑셀, PDF, HWPX, HWP, 백업 파일, 실행파일은 `.gitignore`로 제외합니다.
- 신청자 개인정보가 포함된 실제 데이터 파일은 GitHub에 올리지 않습니다.
- GitHub에는 정적 HTML과 문서만 배포합니다.
